## How this library is used

When building a website, search by a combination of:

- component: hero, navbar, card, CTA, pricing, testimonial, form, footer, modal, accordion, loader, slider
- visual style: minimal, premium, SaaS, agency, editorial, dark, glassmorphism, brutalist, 3D
- interaction: hover, reveal, scroll, parallax, cursor, marquee, morph, magnetic, sticky
- technology: CSS, vanilla JS, GSAP, SVG, Canvas, Swiper
- responsive requirement: mobile-first, responsive, desktop, touch

The goal is to select references first and then adapt the underlying design pattern to the current site's content, brand and responsive requirements rather than blindly copying a Pen.
