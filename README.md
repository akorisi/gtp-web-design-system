# GTP Web Design System

A searchable design-component library for building websites with ChatGPT.

## Purpose

This repository stores references and reusable design components discovered from public CodePen examples and other compatible sources. Components are organized by UI pattern so they can be searched and adapted when building websites.

## Categories

- `heroes/` — hero sections and landing-page headers
- `navigation/` — navbars, menus, mobile navigation
- `buttons/` — buttons, CTAs and micro-interactions
- `cards/` — content, feature and product cards
- `pricing/` — pricing tables and plans
- `testimonials/` — testimonials, reviews and social proof
- `forms/` — forms, inputs and validation UI
- `footers/` — footer layouts
- `animations/` — transitions, reveals and motion patterns
- `backgrounds/` — gradients, particles, mesh and visual backgrounds
- `effects/` — hover, cursor, scroll and other visual effects

## Component record

Each component should document:

- source URL
- author, when available
- source license / usage notes
- category
- tags
- design summary
- relevant HTML/CSS/JS or implementation notes
- dependencies and external assets
- responsive considerations

## Important

Do not bulk-scrape or mirror CodePen. Add references and implementation material only where the source permits reuse and in accordance with applicable terms and licenses.
